# Local rollback — AI4SCIENCE Template v0.1.0

## Scope

This is a local template release. No external repository, service, registry, journal, dataset, model host, or deployment was changed.

## Rollback procedure

1. Stop distributing or reusing `ai4science-template-v0.1.0`.
2. Preserve this directory and its SHA-256 manifest as the release audit record.
3. Publish corrections as a new version directory; do not overwrite this release directory.
4. If removal is explicitly authorized, move this exact version directory and its ZIP archive to an approved archive location and update the formal release record.

## Limitation

Local rollback cannot revoke manually copied files outside this workspace.
