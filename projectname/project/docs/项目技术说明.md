# 项目技术说明

本项目目前是科研项目模板，目的是让实际问题、实现、结果与必要决定有清楚的位置。它提供组织起点，不代表已完成某种算法或产品。

## 问题与方案

实际使用者首先需要明确谁遇到什么问题、输入材料是什么，以及希望观察到什么结果。选定问题后只启用解决该问题需要的能力，解释方案为何适合当前限制；不能把目录中预留的组件当作已经可用。

## 当前范围

现有能力是模板安排、最小日记录约定及内部维护检查。具体研究方法或业务功能、数据条件与成功标准尚未建立，须在真实项目中依据材料说明。工程检查能够发现结构问题，不能证明科学先进性或产品满足用户目标。

## 实际项目填写要求

用连贯文字解释问题、方案、输入输出与必要条件；重要术语首次解释。实现细目留在源资料，正文只保留影响读者理解方案和适用范围的信息。结果与边界在另一份结果说明中维护，不复制多套正文。
