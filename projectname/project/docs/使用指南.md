# 使用指南

当前没有可供运行的具体科研计算或产品业务流程，不能把模板工具当成目标系统。使用者应先建立真实项目并确认实际输入与已实现入口。

## 开始前

准备用户需求、可用材料、允许使用的数据与资源，以及观察完成的条件。没有获准数据或尚无实现时明确记录缺项，不编造示例结果填满文档。

## 建立与使用

按需要选择工程能力和必要目录，设置唯一项目标识；随后实现最小可观察结果，并依据真实入口补充用户操作。操作说明应回答准备什么、做什么、看到什么以及失败时如何处理。未选服务、部署方式或实验不应出现在可复制的快速开始中。

## 继续与恢复

已批准目标中的必要修复和恢复持续进行；从已有运行状态接续，不重复已经完成的单元。超出资源、数据权限或科学条件时说明影响，只暂停有关部分。源资料及机器诊断由维护者查询，用户正文不堆检查流水。
