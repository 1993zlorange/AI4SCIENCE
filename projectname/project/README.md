## 使用边界

工程根保存已选择的代码、配置、测试及必要环境。正式专题成果归上级achieve；原始运行和机器检查留既有run/output，不复制成用户过程报告。未选择能力不因模板目录存在而启用，不创建无调用方的服务或空白业务。

## 工作方式

先读根和工程AGENTS以及编程规范，按明确目标实现与检查；范围和决定只写当天需求，重要真实进度只写当天日志。同一授权内的必要修复、断点恢复、汇总与复核持续进行，不另建契约、成果卡或交接文件。
