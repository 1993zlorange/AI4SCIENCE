## 2.1 原因与影响

- 为什么做（why）：用户要求统一参考资料命名，避免日期后缀、无类型名称和无日期名称降低检索、排序与归档可读性。
- 预期影响（expected_impact）：科研流程、SR 工作流、负责人说明与目录设计材料可按日期和类型稳定定位，根级 README 不再指向旧位置。
- 实际影响（actual_impact）：7 个资产和 3 处活动路径已规范化；未改变任何科研内容或实施行为。
- 受影响需求（affected_requirements）：DOC-SR-REF-01、DOC-SR-REF-02。
- 受影响文件（affected_files）：`reference/` 下 7 个资产、`README.md`、两份 SR 说明与本批治理记录。
- 受影响下游（affected_downstream）：科研项目启动、工作流编排、负责人使用说明查阅和参考材料检索。
- 决策依据（decision_basis）：用户明确请求；根级 AGENTS 的日期化文档命名规则。
