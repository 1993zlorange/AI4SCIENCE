# 十二工作流交接目录需求记录

## 用户要求

根据根级科研治理规则，为 12 个科研工作流创建对应的交接目录。

## 范围与验收

| 项目 | 内容 |
|---|---|
| 实施目录 | `projectname/achieve` |
| 目标 | 创建表中规定的 12 个工作流交接目录 |
| 范围外 | 不创建成果卡、交接书正文、模板或科研结论；不移动既有目录 |
| 验收 | 12 个目标路径存在，所属八类成效目录正确，既有文件未被修改 |
| 首个具体产物 | 各工作流后续真实交接书，文件名按日期规则生成 |
| 生命周期 | 工作流交接目录长期保留，承载对应工作流的交接书 |
| 责任 | 各工作流主责 Agent；目录归档由项目监理维护 |
