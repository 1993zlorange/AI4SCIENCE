# 项目治理机制说明文档类型登记

| 项目 | 内容 |
|---|---|
| 文档类型名称 | 项目治理机制说明 |
| 目的 / 非目标 | 解释项目治理规则、实际机制、Agent 协同、流程和限制；不替代需求、架构、测试、科研成果卡或正式验收 |
| 负责人 / 评审人 | 项目监理或项目经理 / 用户或项目建立责任人 |
| 扩展名与命名模式 | Markdown；`YYYYMMDD-内容简述-机制说明.md` |
| 项目内目录 | `projectname/achieve/00-项目管理/supervision/` |
| 适用 Skill | 项目监理、项目治理、项目经理文档审查 |
| 中文空白模板路径 | `projectname/achieve/00-项目管理/templates/20260912-项目治理机制说明-模板.md` |
| 必填结构/字段 | 元数据、范围、证据、治理架构、记录机制、命名归属、Skill/脚本、AGENTS 协同、监管流程、检查结果、限制、追溯和变更 |
| 证据与追溯 | 引用项目相对路径、配置、Agent/Skill 标识、检查命令及状态；事实、推断和待决定事项分开 |
| 敏感性与权限 | 默认项目内部；不得写入凭据、机器绝对路径或未经批准的科研结论 |
| 保留、归档和清理 | 作为治理基线随项目保留；新版本使用新生产日期，不覆盖已引用版本 |
| 验证方法 | Markdown 结构、配置/路径、引用、命名、UTF-8、覆盖完整性和适用流程图检查 |
