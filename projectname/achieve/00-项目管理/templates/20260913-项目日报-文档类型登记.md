# 项目日报文档类型登记

| 项目 | 内容 |
|---|---|
| 文档类型名称 | 项目日报 |
| 目的 / 非目标 | 按文件名日期汇总项目日志中的实际事实、验证、问题、影响、成本和下一步；不替代源日志、验收或科研结论。 |
| 负责人 / 评审人 | 项目监理 / 项目责任人。 |
| 扩展名与命名模式 | Markdown；`YYYYMMDD-摘要-日报.md`。 |
| 项目内目录 | `projectname/achieve/00-项目管理/dailylogs/`。 |
| 适用 Skill | `pr-ps-09-daily-log-summary`。 |
| 中文空白模板路径 | `projectname/project/.codex/skills/pr-ps-09-daily-log-summary/assets/20260913-项目日志日报汇总-输出模板.md`。 |
| 必填结构/字段 | 报告日期、生成时间、输入目录、来源清单、筛选统计、摘要、完成事项、变更影响、验证、问题阻塞、成本时间、未完成项和结论边界。 |
| 证据与追溯 | 所有关键事实引用项目相对源日志路径；日期来自文件名前缀。 |
| 敏感性与权限 | 默认项目内部；不得复制凭据、敏感样本或不必要的绝对路径。 |
| 保留、归档和清理 | 日报作为管理成效随项目保留；同名不覆盖，修订使用更明确摘要或经授权的新版本。 |
| 验证方法 | 文件名/日期、来源快照、事实追溯、占位符、敏感信息和治理校验。 |

## 决定记录

- 与现有类型的重叠：项目日志记录单次动作，项目日报只汇总多个源日志；不复制或替代源日志。
- 试点：当前项目 2026-09-13 日志。
- 人工决定：用户已批准新增全局 Skill 和该日报输出类型。
