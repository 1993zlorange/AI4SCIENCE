# 工程运行日志文档类型登记

| 项目 | 内容 |
|---|---|
| 文档类型名称 | 工程运行日志模板 |
| 目的 / 非目标 | 统一 `Reporter` 产生的运行事件字段、路径、格式、脱敏和终态记录；不替代项目管理日志、成果卡或真实运行日志实例。 |
| 负责人 / 评审人 | 工程维护者 / 项目监理与代码评审者。 |
| 扩展名与命名模式 | Markdown 模板采用 `YYYYMMDD-工程运行日志-模板.md`；运行事件固定为 `<run_id>/logs/events.jsonl`。 |
| 项目内目录 | 模板：`projectname/project/docs/`；运行实例：`projectname/project/var/runs/<YYYYMMDD>/<run_id>/logs/`。 |
| 适用 Skill | 工程实现、运行验证、项目监理。 |
| 中文空白模板路径 | `projectname/project/docs/20260913-工程运行日志-模板.md` |
| 必填结构/字段 | 用途边界、运行路径、事件必填字段、可选字段、示例、端口职责、验收清单。 |
| 证据与追溯 | 运行日志以 `run_id` 关联 manifest、解析配置、指标与 artifacts；模板链接至 `PROGRAMMING_STANDARDS.md` 与 README。 |
| 敏感性与权限 | 默认内部工程资料；日志禁止含凭据、敏感原始样本、连接串和不必要的绝对路径。 |
| 保留、归档和清理 | 模板长期保留；运行实例遵循运行数据保留策略且不提交 Git。 |
| 验证方法 | Markdown 结构与链接检查、F001 治理校验；实现后补充 JSONL schema/contract 与临时目录集成测试。 |

## 决定记录

- 与现有类型的重叠：项目管理日志记录治理动作；本类型只定义工程运行事件，二者不合并。
- 试点：下一次实现 `Reporter` 本地 adapter 的工程运行。
- 人工决定：用户已要求补充模板与规范；不包含自动实现或全局发布决定。
