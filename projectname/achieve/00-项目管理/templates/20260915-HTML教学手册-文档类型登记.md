# HTML教学手册文档类型登记

| 项目 | 内容 |
|---|---|
| 文档类型名称 | HTML 教学手册 |
| 目的 / 非目标 | 目的：面向新手的学习型手册，用导航、示例、表格和流程说明降低理解成本；非目标：不承担科学结论、验收证据、代码测试或发布包职责 |
| 负责人 / 评审人 | 项目监理 / 文档维护者或项目监理 |
| 扩展名与命名模式 | `YYYYMMDD-内容简述-教学手册.html` |
| 项目内目录 | 正式工程手册：`projectname/project/docs/`；空白模板：`projectname/achieve/00-项目管理/templates/` |
| 适用 Skill | 项目监理技能；外部 Diátaxis 教学文档原则仅作方法参考 |
| 中文空白模板路径 | `projectname/achieve/00-项目管理/templates/20260915-HTML教学手册-模板.html` |
| 必填结构/字段 | 页面元信息、读者对象、学习地图、章节导航、通俗正文、常见误区、速查表、源文档追溯、版本信息 |
| 证据与追溯 | 必须列出输入源文档的项目相对路径；不得把参考 PDF/图片复制为第二事实源 |
| 敏感性与权限 | 不包含密钥、绝对机器路径、未许可数据或未批准科学结论 |
| 保留、归档和清理 | 重大演进新增日期文件；过时版本经变更记录后归档或删除 |
| 验证方法 | HTML 语法/标题锚点/相对资源路径检查；浏览器打开与响应式/打印检查；治理校验器 |

## 决定记录

- 与现有类型的重叠：不同于普通 Markdown 技术方案和流程说明；强调面向学习者的交互式 HTML 呈现。
- 试点：`projectname/project/docs/20260915-AI4SCIENCE教学手册-教学手册.html`。
- 人工决定：用户明确要求 HTML 形式；本轮作为本地模板文档试点执行。
