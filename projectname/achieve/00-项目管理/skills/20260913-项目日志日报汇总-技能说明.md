# pr-ps-09-daily-log-summary 技能提案

## 1. 需要解决的重复问题

- 需求/问题/反思证据：用户明确要求形成按日重复执行的日志日报能力；当前项目日志目录已有跨日期、多文件管理日志。
- 现有 Skill 的覆盖缺口：`pr-ps-03-project-logging` 负责单次事实日志，不负责跨文件按日期汇总；历史工具包只有旧式 `daily-log.md` 模板，没有主动 Skill、日期筛选或证据追溯契约。
- 预期收益与测量方式：减少人工逐文件整理；以匹配/排除数、来源覆盖率、无证据陈述、覆盖冲突和人工纠正次数衡量。

## 2. Skill 契约

| 项目 | 内容 |
|---|---|
| 代号与英文名称 | `pr-ps-09-daily-log-summary` |
| 中文显示名称 | 项目日志日报汇总 |
| 单一职责 | 读取一次输入快照中的本地项目日志，按文件名日期生成事实可追溯的中文日报。 |
| 触发条件 / 非目标 | 触发：操作者要求生成某日、日期范围或全部日期的日志日报；非目标：修改源日志、推断未记录事实、总结日期不在文件名中的记录。 |
| 输入 / 输出 | 输入为操作者指定目录或当前项目管理日志默认目录；输出为 `dailylogs/YYYYMMDD-摘要-日报.md`。 |
| 失败边界 | 项目根、目录、日期或权限无效，目标重名，来源不可读或校验失败时停止相关日期写入并报告。 |
| 权限与副作用 | 只读获准源目录，仅在当前项目 `dailylogs/` 新增日报；不联网、不覆盖、不提交、不发布。 |
| 幂等与并发 | 同名保护确保重复运行不新增同名文件；写入前复核目标，冲突时停止。 |
| 维护人 | 项目监理 |

## 3. 文档输出与模板

- 是否生成文档：是。
- 文档类型、命名和落点：项目日报，`YYYYMMDD-摘要-日报.md`，落点为当前项目 `achieve/00-项目管理/dailylogs/`。
- 中文空白模板路径：`projectname/project/.codex/skills/pr-ps-09-daily-log-summary/assets/20260913-项目日志日报汇总-输出模板.md`。

## 4. 试点、验证与决定

- 试点范围：当前项目 2026-09-13 管理日志；不递归、不覆盖、不联网。
- 正常/边界/失败/重复执行验证：正常场景生成 1 份日报；3 个当日日志匹配、3 个其他日期日志排除、0 个读取失败；不存在目录被拒绝；同名冲突被识别且重复执行未新增文件；源日志哈希未变化。
- 成功率、误触发率、耗时和维护成本：首轮正常场景 1/1 成功、误触发 0；生成和本地检查为短时操作，未单独计量人工耗时；长期指标仍需后续日报样本。
- 回滚：从全局 Skill 根移除同名安装目录；项目候选和晋升记录保留以供审计，除非另有明确删除授权。
- 人工决定：用户已明确要求创建全局 Skill；F002 审计 0 错误，已安装与项目候选包哈希一致的全局版本 1.0.0。
