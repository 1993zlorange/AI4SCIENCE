# 项目治理校验器 API 说明

## 1. 用途

只读检查项目功能注册表、治理配置、目录边界和日期化文档提示，不创建、移动、删除或覆盖文件，不联网，不读取凭据。

## 2. 入口与参数

```text
python scripts/f001_governance_validate.py --project-root <项目工程目录> --check
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `--project-root` | 否 | 工程目录；默认当前目录 |
| `--check` | 否 | 统一入口参数；执行只读检查 |

## 3. 输出与退出码

- `ERROR`：配置缺失、功能注册表字段缺失/重复或发现未登记空目录。
- `WARNING`：文档/配置未采用日期化名称，需人工确认是否属于固定技术入口。
- 退出码 `0`：无 ERROR；退出码 `1`：存在 ERROR。

## 4. 安全、幂等与限制

- 重复运行只读且结果应一致；不自动修复历史文件。
- 当前注册表采用 JSON 兼容 YAML，避免新增运行时依赖。
- 不替代真实测试、质量门、科研阶段门或人工批准。

## 5. 验证记录

- 语法检查：`python -m py_compile scripts/f001_governance_validate.py`
- 试运行：`python scripts/f001_governance_validate.py --project-root . --check`
