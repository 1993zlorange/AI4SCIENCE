# Skill 晋升审查器 API 说明

## 1. 用途

只读检查项目 Skill 是否具备试点、独立评审、安全扫描、人工批准、全局安装记录和回滚证据；不执行全局安装或修改全局目录。

## 2. 入口与参数

```text
python scripts/f002_skill_promotion_audit.py --project-root <项目工程目录> --check
```

## 3. 输出与退出码

- 无待晋升项：输出信息并以 `0` 退出。
- 待晋升项缺少证据：输出 `ERROR` 并以 `1` 退出。
- 全局安装字段仅代表已授权安装的证据引用，不代表本工具已执行安装。

## 4. 安全、幂等与回滚

- 只读读取 `configs/skill-promotion.yaml`，不联网、不读取凭据、不写全局 Skill。
- 重复运行幂等；安装必须由人工批准的独立步骤执行并记录哈希与回滚路径。
